# Bybit Expense Tracker — test build

A built copy of the front end, published so it can be deployed and tested. It
carries **no source, no specification and no credentials** — those live in the
private repository this build came from.

Nothing here talks to a server. The application is local-first: transactions,
settings and any Bybit credentials stay in an encrypted vault in your browser
(AES-256-GCM under PBKDF2-SHA256), and the host serves static files and learns
nothing.

## Trying it

1. Open the deployed URL.
2. Create a vault with a password. It protects local data only and cannot be
   reset, so use something you will remember.
3. **Настройки → Bybit Pay → Загрузить CSV-экспорт** with a Bybit Pay export, or
   the sample below.
4. Go back to **Операции**.

rate under **Курсы валют** — an amount in a currency with no rate is left out of
the total and named in a banner rather than counted at a guessed rate.

## What to look at

The transfer on 16 August should **not** count towards spending, and the refund
on 17 August should reduce it. Re-importing the same file should add nothing.
